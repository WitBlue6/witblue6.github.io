MemSearch RL

Research Prototype

A Qwen2.5-7B-based agent for multi-hop question answering under a fixed retrieval budget and a 512-token evidence-memory limit.

  • System Design: Separate search, memory-management and answer modules; BM25 retrieval, evidence updates, and final answers with source citations.
  • Staged RL: LoRA + GRPO first trains evidence retention with fixed retrieval and answering; then trains query rewriting and stopping with the memory and answer modules frozen.
  • Reward Design: Final-answer F1 and invalid-action penalties guide policy updates.
  • Evaluation Scope: Results reported on a 200-question HotpotQA candidate-pool evaluation; memory-policy RL improved F1 by 3.00%, with an additional 1.97% improvement after search-policy RL.

F1 +5.63%: Compared with the fixed-summary baseline in the reported 200-question evaluation.

Search Calls -46.15%: Reduction in average search count in the same evaluation.
